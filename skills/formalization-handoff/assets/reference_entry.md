## [ReferenceKey]

- **Type:** paper
- **Authors:** Full author list
- **Title:** Exact title
- **Version/Year:** Version or edition and year
- **Stable identifier/URL:** DOI, ISBN, arXiv identifier, or stable https URL
- **Precise locator:** Theorem/lemma/section/chapter/page/equation and any version caveat
- **Local source path:** refs/paper.pdf

Use a path relative to the selected research problem. Write `Not downloaded`
only when no local authoritative copy exists.
