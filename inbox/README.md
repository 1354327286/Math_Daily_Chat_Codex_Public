# Research Inbox

Place cross-problem discussions, not-yet-assigned material, unprocessed research reports, imported notes, and temporary source documents in this directory. Its contents remain local and are ignored by Git; only this README is part of the public project framework.

After organizing an inbox document, preserve the original locally unless the user explicitly asks to remove it. Write audited outcomes separately into every affected problem directory; do not use the inbox document as a problem's current state page.
